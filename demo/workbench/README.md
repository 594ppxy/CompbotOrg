# 单文件工作台（联网版）

一个零依赖、单 HTML 的三栏 AI 组织工作台。直接双击 `index.html` 就能跑，也可以丢到任意静态托管上。

这是 `ds-bot` 宿主的一个**独立可视化样机**：它复用同一套组织模型（部门 / 员工 / 项目 / 任务 / 状态机）和同一份视觉规范（`--bt-*` 设计令牌、圆角阶梯），但把运行时换成了浏览器里的纯前端状态，用来快速验证交互与 AI 编排，不受宿主构建链约束。

## 跑起来

```bash
python3 build.py          # 把 src/ 内联成 index.html
open index.html
```

`src/` 的结构：`head.html`（设计系统 CSS）→ `app.css`（视图层）→ `body.html`（骨架）→ `app.js`（状态驱动的渲染与 AI 调用）。`build.py` 只做内联，没有打包器、没有依赖。

## 接模型

打开 **设置 › 模型**，填三项：

| 字段 | 说明 |
|---|---|
| 接口地址 | 任何 OpenAI 兼容的 `/v1` 地址，默认 `https://apihub.agnes-ai.com/v1` |
| API Key | 保存到当前浏览器的 `localStorage` |
| 模型名称 | Agnes 用 `agnes-2.5-flash`；换 DeepSeek / Kimi / Ollama 只改地址和模型名 |

点「保存并测试」，状态变绿即通。不填 Key 时对话走本地规则回复，界面功能不受影响。

也可以用一次性链接省去手填：`index.html#k=sk-xxxx`。页面读到后写入 `localStorage`，随即用 `history.replaceState` 把 hash 抹掉——**hash 不会发给服务器**，页面源码里也不含任何密钥。

## AI 到底做了什么

不是「接了个聊天框」，每次请求都会把当前组织状态塞进 system prompt：

- 部门与成员名单（姓名 + 职位）
- 每个项目的状态、百分比、负责人、目标、截止日
- 当前这个员工名下的任务与进度
- 全公司阻塞项及其原因

回复以 SSE 流式返回，逐字上屏。模型被要求用 IM 口吻说话、只引用真实数据。

更关键的是**回写**：当模型决定把某件事交办出去，它会在正文后输出一行

```
[[TASK]]任务名|负责人姓名|所属项目名
```

前端解析这些行，按姓名匹配到具体员工、按项目名匹配到具体项目，**真的在 `DB.tasks` 里创建任务**，重算项目进度，把员工状态从「空闲」置为「工作中」，并在消息气泡下方渲染成可点击的任务条。所以「CEO 派活」不是文案，是数据变更——任务看板和项目视图会立刻反映出来。

## 已验证

用 Chromium 实测过：Key 导入、连接测试、切员工后身份隔离（Backend AI 用自己的任务数据回答）、连续追问的上下文保持、跨会话不串台、无效 Key 的报错与红条提示、深色模式、680px 窄屏、任务创建后左栏计数同步。

## 边界

- 组织数据在内存里，刷新回到初始示例；只有模型配置持久化。
- 没有后端，Key 在浏览器端使用。仅适合个人/演示，不适合对外多租户分发。
- 单文件大小约 260 KB，`head.html` 里的设计系统 CSS 占了大头。
