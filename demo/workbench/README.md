# 单文件工作台（联网版）

一个零依赖、单 HTML 的三栏 AI 组织工作台。直接双击 `index.html` 就能跑，也可以丢到任意静态托管上。

这是 `ds-bot` 宿主的一个**独立可视化样机**：它复用同一套组织模型（部门 / 员工 / 项目 / 任务 / 状态机）和同一份视觉规范（`--bt-*` 设计令牌、圆角阶梯），但把运行时换成了浏览器里的纯前端状态，用来快速验证交互与 AI 编排，不受宿主构建链约束。

## 跑起来

```bash
python3 build.py          # 把 src/ 内联成 index.html
open index.html
```

`src/` 的结构：`head.html`（设计系统 CSS）→ `app.css`（视图层）→ `body.html`（骨架）→ `app.js`（状态驱动的渲染与 AI 调用）。`build.py` 只做内联，没有打包器、没有依赖。

## 接模型

打开 **设置 › 模型**，填三项：

| 字段 | 说明 |
|---|---|
| 接口地址 | 固定 Agnes `https://apihub.agnes-ai.com/v1`（OpenAI 兼容） |
| API Key | 仅保存到当前浏览器标签页的 `sessionStorage`；关闭标签页即清除 |
| 模型名称 | `agnes-2.5-flash` |

点「保存并测试」，状态变绿即通。**工作台只有 Agnes 一条回复路径**：未配置 Key 时发送键会被拦下并提示去设置，不会产生任何本地规则回复，也不会凭用户原话猜测派单；所有答复与所有 `[[TASK]]` 派单指令都来自模型。模型调用失败时只显示明确错误，同样不回退到假回复。

为避免密钥出现在链接、历史记录或持久化存储中，样机不再支持通过 URL 传入 Key。请在设置页粘贴 Key；关闭标签页后需重新填写。

## AI 到底做了什么

不是「接了个聊天框」，每次请求都会把当前组织状态塞进 system prompt：

- 部门与成员名单（姓名 + 职位）
- 每个项目的状态、百分比、负责人、目标、截止日
- 当前这个员工名下的任务与进度
- 全公司阻塞项及其原因

回复以 SSE 流式返回，逐字上屏，生成中可随时点 ■ 停止；已输出的部分会保留并标记「（已停止）」。正文未开始就停止不会留下半截消息。

更关键的是**回写**：当模型决定把某件事交办出去，它会在正文后输出一行

```
[[TASK]]任务名|负责人姓名|所属项目名
```

前端解析这些行，按姓名匹配到具体员工、按项目名匹配到具体项目，**真的在 `DB.tasks` 里创建任务**，重算项目进度，把员工状态从「空闲」置为「工作中」，并在消息气泡下方渲染成可点击的任务条。协议行在流式过程中就被隐藏，用户看不到裸标记。

## 交互覆盖

| 能力 | 说明 |
|---|---|
| 三栏导航 | rail 每一项都换左栏、中栏、Inspector，不是只换标题 |
| 会话隔离 | 每个员工独立会话，切人不串台，占位符跟随对象 |
| 多行输入 | `Enter` 发送，`Shift+Enter` 换行，输入框自动增高至 140px 上限 |
| 停止生成 | 生成中发送键变为 ■，中止后保留已输出内容 |
| 重发 | 回填输入框并清掉这条之后的内容，不会再追加重复消息 |
| 任务编辑 | 状态改为分段按钮、进度滑块、负责人下拉；改动即时重算项目进度并推导员工状态 |
| 文档阅读 | 知识库点进去是真正的正文（内置简易 Markdown 渲染：标题、表格、列表、代码） |
| 文档编辑 | 新建、导入本地 `.md/.txt`、在线改标题与正文；种子文档的改动也会持久化，刷新不丢 |
| 生成周报 | 从项目任务实况生成周报草稿，落成一篇文章进知识库 |
| 排序与开关 | 知识库按更新时间/名称排序、部门成员按状态排序、每日摘要开关都是真实状态 |
| 持久化 | 会话、任务、新建/导入/编辑过的文档和不含 Key 的模型配置存在 `localStorage`；未发出的输入草稿按会话保留，切视图不丢；Key 仅保存在当前标签页；重置按钮恢复初始示例 |
| 搜索 | 独立输入容器，中文输入法组字期间不重建 DOM |

## 已验证

用 Chromium 实测（32 项断言全绿）：未配置 Key 时发送被拦截、草稿保留、无伪造回复与派单；接上 Agnes 后 SSE 流式上屏、`[[TASK]]` 真实建任务、`dispatched` 送达回执、@ 抄送与派单通知；模型 401 时只报错误不回退；文档新建/编辑/刷新持久化、排序、通知开关、深色模式、900px 窄屏。控制台零 JS 错误。

## 边界

- 没有后端，Key 在浏览器端直连 Agnes；适合个人使用，不适合对外多租户分发。页面只接受 HTTPS 接口地址，本机 `localhost` 开发除外。若要开箱即用或多租户分发，需要加一层服务端代理，把 Key 放在环境变量里。
- 持久化用 `localStorage`，清缓存即丢；跨设备不同步。
- 单文件约 280 KB，`head.html` 里的设计系统 CSS 占了大头。
