# 单文件工作台（联网版）

一个零依赖、单 HTML 的三栏 AI 组织工作台。直接双击 `index.html` 就能跑，也可以丢到任意静态托管上。

这是 `ds-bot` 宿主的一个**独立可视化样机**：它复用同一套组织模型（部门 / 员工 / 项目 / 任务 / 状态机）和同一份视觉规范（`--bt-*` 设计令牌、圆角阶梯），但把运行时换成了浏览器里的纯前端状态，用来快速验证交互与 AI 编排，不受宿主构建链约束。

## 跑起来

```bash
python3 build.py          # 把 src/ 内联成 index.html
open index.html
```

`src/` 的结构：`head.html`（设计系统 CSS）→ `app.css`（视图层）→ `body.html`（骨架）→ `app.js`（状态驱动的渲染与 AI 调用）。`build.py` 只做内联，没有打包器、没有依赖。

## 接模型

打开 **设置 › 模型**，填三项：

| 字段 | 说明 |
|---|---|
| 接口地址 | 固定 Agnes `https://apihub.agnes-ai.com/v1`（OpenAI 兼容） |
| API Key | 仅保存到当前浏览器标签页的 `sessionStorage`；关闭标签页即清除 |
| 模型名称 | `agnes-2.5-flash` |

点「保存并测试」，状态变绿即通。**工作台只有 Agnes 一条回复路径**：未配置 Key 时发送键会被拦下并提示去设置，不会产生任何本地规则回复，也不会凭用户原话猜测派单；所有答复与所有 `[[TASK]]` 派单指令都来自模型。模型调用失败时只显示明确错误，同样不回退到假回复。

流式解析对响应形态是宽容的：`choices[0].delta.content`、纯文本 `delta`、`choices[0].text`、非 SSE 的整包 JSON、以及最后一块没有换行的情况，都能正常上屏。真的拿到空内容时，报错会带上服务端返回的原始片段（例如 `收到：data: {"choices": [{"delta": {}}]}`）并列出常见原因，而不是只丢一句「空内容」让你无从下手。

为避免密钥出现在链接、历史记录或持久化存储中，样机不再支持通过 URL 传入 Key。请在设置页粘贴 Key；关闭标签页后需重新填写。

## AI 到底做了什么

不是「接了个聊天框」，每次请求都会把当前组织状态塞进 system prompt：

- 部门与成员名单（姓名 + 职位）
- 每个项目的状态、百分比、负责人、目标、截止日
- 当前这个员工名下的任务与进度
- 全公司阻塞项及其原因

回复以 SSE 流式返回，逐字上屏，生成中可随时点 ■ 停止；已输出的部分会保留并标记「（已停止）」。正文未开始就停止不会留下半截消息。

更关键的是**回写**：当模型决定把某件事交办出去，它会在正文后输出一行

```
[[TASK]]任务名|负责人姓名|所属项目名
```

前端解析这些行，按姓名匹配到具体员工、按项目名匹配到具体项目，**真的在 `DB.tasks` 里创建任务**，重算项目进度，把员工状态从「空闲」置为「工作中」，并在消息气泡下方渲染成可点击的任务条。协议行在流式过程中就被隐藏，用户看不到裸标记。

## 交互覆盖

| 能力 | 说明 |
|---|---|
| 三栏导航 | rail 每一项都换左栏、中栏、Inspector，不是只换标题 |
| 会话隔离 | 每个员工独立会话，切人不串台，占位符跟随对象 |
| 多行输入 | `Enter` 发送，`Shift+Enter` 换行，输入框自动增高至 140px 上限 |
| 停止生成 | 生成中发送键变为 ■，中止后保留已输出内容 |
| 重发 | 回填输入框并清掉这条之后的内容，不会再追加重复消息 |
| 任务编辑 | 状态改为分段按钮、进度滑块、负责人下拉；改动即时重算项目进度并推导员工状态 |
| 文档阅读 | 知识库点进去是真正的正文（内置简易 Markdown 渲染：标题、表格、列表、代码） |
| 文档编辑 | 新建、导入本地 `.md/.txt`、在线改标题与正文；种子文档的改动也会持久化，刷新不丢 |
| 生成周报 | 从项目任务实况生成周报草稿，落成一篇文章进知识库 |
| 排序与开关 | 知识库按更新时间/名称排序、部门成员按状态排序、每日摘要开关都是真实状态 |
| 持久化 | 会话、任务、新建/导入/编辑过的文档和不含 Key 的模型配置存在 `localStorage`；未发出的输入草稿按会话保留，切视图不丢；Key 仅保存在当前标签页；重置按钮恢复初始示例 |
| 搜索 | 独立输入容器，中文输入法组字期间不重建 DOM |

## 组织是活的：岗位、职级、群聊

成员不是「头像一个 + 一句人设」。每个 Bot 都有 **岗位（title）、级别（level）、部门（dept）、汇报对象（reportsTo）、职责（bio）**：

| 级别 | 含义 |
|---|---|
| L5 | 决策层 |
| L4 | 管理层 |
| L3 | 主管 |
| L2 | 骨干 |
| L1 | 执行 |

`+ 新建 Bot` 里自己定这五项。**头像是 DSHBot 自己的角色，不是仿的**：`ds-characters.js` 由 `node scripts/sync-characters.mjs` 从 `ds-bot/src/client/characters.js` 原样导出，20 个角色的 body / shade / light / eyes 路径全部一致，渲染也走同一套逻辑——身体路径 + 固定色贴片 + 背光面阴影 + 受光面高光，眼睛用 mask 从整个形状里挖空，所以会透出背后底色。CEO 默认就是宿主 Main Bot 那只鲸鱼（`MAIN_LOOK`）。选头像的界面也照搬宿主：5 列角色网格，选中项沿形状描一圈线（`ShapeRing`），下面是 12 色墨盘，含 aurora 渐变。Bot 会自动归到对应部门、进入「组织概览」计数、能出现在群聊成员里。

**群聊按需创建**，两个入口：

1. 人建：`群聊 › + 新建`，勾成员、选负责人（默认取级别最高的那位）；
2. AI 建：模型认为这事需要多人协作时，自己输出 `[[GROUP]]群名|成员,成员|目的`，群就出现了。它还能顺手造人：`[[BOT]]名字|岗位|级别|部门|汇报对象|职责`。

领导层在群里下指令（和 DSHBot 的用法一致）：负责人收到后**在群里直接 @ 人**，一句一条：

```
这周先把接口收掉，我分给两个人：
@Backend AI 今天把 /org 接口的汇报字段补齐，明早给我可跑的版本
@QA AI 出一份联调回归清单，覆盖分页和权限两个分支
[[TASK]]补齐汇报字段|Backend AI|AI Organization v1
[[TASK]]输出联调回归清单|QA AI|AI Organization v1
```

被 @ 的人会立刻收到：群里出现一条点名气泡（头像 + @名字 + 指令 + 该任务的实时状态），他自己的会话里同时多一条「群里 @ 你：…」，随后就是接单、执行、交付。任务落库的那一刻**派单自动触发执行**，不需要谁再去点一下「开始」。

## 员工会话里只有动作，没有寒暄

点开任何一个成员，聊天区不是「收到，我会尽快处理」这类空话，而是可核查的执行流水：

```
接单    领取「接口联调」，开始执行。
执行    读取 organization 数据与现有汇报字段，界定验收口径
执行    补齐 6 个节点的汇报关系，改动落到 src/app.js
执行    本地回归 8 项通过
提交审核 关系网补全 6 个节点，自测 8/8 通过
```

执行回合用独立 prompt：不许寒暄、不许复述任务、不许征求同意，只输出 3–5 行 `[[STEP]]`（做了什么、依据什么、产出什么）加一行 `[[REPORT]]`（可量化的验收结论）。**没有可执行动作就直接标「受阻」并写清原因**，不会含糊过去。

任务因此真的会往前走：`待启动 → 执行中 → 待审核 →（人点通过）→ 已完成`，被打回则带意见重新入队。左侧成员列表里每个人后面跟的就是这一刻的真实状态（`待命 / 待启动 / 执行中 / 待审核 / 阻塞`），一眼能看出谁在踢皮球。

## 已验证

用 Chromium 实测，三套回归共 **84 项断言全绿**：

- 接模型链路（33 项）：未配置 Key 时发送被拦截、草稿保留、无伪造回复与派单；接上 Agnes 后 SSE 流式上屏、`[[TASK]]` 真实建任务、送达回执、@ 抄送与派单通知、派单后员工主动开工并交付；模型 401 时只报错误不回退；文档新建/编辑/刷新持久化、排序、通知开关、深色模式、900px 窄屏。
- 流式解析（6 项，新增）：`delta.content` / 末块无换行 / 纯文本 `delta` / `choices[0].text` / 非 SSE 整包都能正确上屏；真空响应会带出收到的原始片段，而不是干巴巴一句「空内容」。
- @ 派活与头像（20 项，新增）：加载 20 个 DSHBot 角色、CEO 为鲸鱼形象、每个成员角色不同、眼睛 mask 存在、选择器 20 角色 + 12 色、点选后预览与按下态更新、用选中角色建 Bot；群里 @ 到具体成员、@ 以气泡呈现、任务随之创建、被 @ 的人在跑、自己会话收到指令且写清要做什么、真的开干。
- 组织与执行（25 项）：新建 Bot 的岗位/级别/部门正确且刷新后仍在、几何头像生成、未连接时群指令被拦下、建群与成员生效、群指令 → 派单 → 执行 → `review`、员工会话只有动作流且动作带具体内容、负责人回复挂任务卡片、群聊历史刷新不丢、点通过后任务 `done / 100%`、模型自建群聊与新建 Bot、群指令与执行回合期间零 JS 错误。

## 边界

- 没有后端，Key 在浏览器端直连 Agnes；适合个人使用，不适合对外多租户分发。页面只接受 HTTPS 接口地址，本机 `localhost` 开发除外。若要开箱即用或多租户分发，需要加一层服务端代理，把 Key 放在环境变量里。
- 持久化用 `localStorage`，清缓存即丢；跨设备不同步。
- 单文件约 280 KB，`head.html` 里的设计系统 CSS 占了大头。
